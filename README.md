# Online Graphic Editor

A browser-based graphic editor for quick image and visual edits.

## Features

- Edit graphics directly in the browser
- Open images from local files
- Add text and shapes
- Apply basic image filters
- Export/download the result
- Import/export project JSON
- No account required
- No server-side storage

## Privacy

This tool is designed to run locally in the user's browser.

Images and values entered by the user are not intentionally sent to external services, stored on a server, or logged by this project.
